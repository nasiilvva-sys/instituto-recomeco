# Instituto Recomeço

Projeto desenvolvido para o Instituto Recomeço, com foco em apresentar projetos e ações sociais e facilitar o cadastro de voluntários.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git e GitHub

## Versionamento

O projeto utiliza Git para controle de versões, com as branches `main`, `develop` e `feature/acessibilidade`.

A versão `v1.0.0` representa a primeira versão estável do projeto.

## Acessibilidade

Foram implementadas melhorias de acessibilidade relacionadas à navegação, foco dos elementos e organização visual da interface.

## Estrutura

- `html/` — páginas HTML
- `css/` — estilos
- `js/` — scripts JavaScript
- `Imagens/` — imagens utilizadas no projeto
