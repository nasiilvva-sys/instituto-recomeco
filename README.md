# Instituto Recomeço

Projeto desenvolvido para o Instituto Recomeço, com foco em apresentar projetos e ações sociais e facilitar o cadastro de voluntários.

## Tecnologias utilizadas

- **HTML5** — estrutura das páginas do projeto.
- **CSS3** — estilização, layout e organização visual.
- **JavaScript** — interatividade e funcionalidades.
- **Git** — controle de versões do projeto.
- **GitHub** — hospedagem do repositório e gerenciamento do desenvolvimento.

## Como executar localmente

1. Clone o repositório do projeto a partir do GitHub.
2. Abra a pasta do projeto no WebStorm ou em outro editor de código.
3. Acesse a pasta `html/`.
4. Abra o arquivo `index.html` no navegador.
5. Navegue pelas páginas e funcionalidades disponíveis no projeto.

Por se tratar de uma aplicação FrontEnd estática, não são necessárias dependências externas ou etapas de build para sua execução básica.

## Versionamento

O projeto utiliza o **Git** para controle de versões e o **GitHub** para hospedagem e colaboração.

Foram utilizadas as seguintes branches:

- `main` — versão principal e estável do projeto.
- `develop` — branch destinada ao desenvolvimento contínuo.
- `feature/acessibilidade` — utilizada para implementar melhorias de acessibilidade.
- `docs/github-versionamento` — utilizada para adicionar a documentação inicial do projeto.

As alterações foram registradas utilizando mensagens de commit seguindo o padrão **Conventional Commits**, facilitando a identificação do objetivo de cada alteração.

A primeira versão estável do projeto foi identificada pela tag:

`v1.0.0`

## Acessibilidade

Foram implementadas melhorias de acessibilidade com o objetivo de tornar a interface mais organizada e facilitar a navegação dos usuários.

Entre as melhorias realizadas estão ajustes relacionados à navegação, foco dos elementos e organização visual da interface.

## Objetivo do projeto

O projeto tem como objetivo apresentar as ações e projetos do Instituto Recomeço e disponibilizar uma interface para cadastro de voluntários, utilizando recursos de desenvolvimento FrontEnd e práticas de organização, versionamento e acessibilidade.
